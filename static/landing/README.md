# PUP Lopez Academic Scheduling System – Capstone Landing Page

Plain HTML/CSS/JS (no build step).

## Edit in VS Code
1. Open this folder: `File > Open Folder > capstone-site`
2. Install the **Live Server** extension, right-click `index.html` > **Open with Live Server**

## Where to edit
- Text and sections: `index.html` (look for `TODO` comments: system link, adviser/panel)
- Brand colors and fonts: top of `css/style.css` (`:root` variables)
- Images: `assets/` (logo.png, dashboard.png). Swap in cleaner screenshots with the same filenames.

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel.
